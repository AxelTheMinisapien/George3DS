# Introducing George Pig's Adventure 3DS!
George Pig's Adventure 3DS is a demake of the bootleg flash game with the same name.

## How To Play
A - Jump
Circle Pad/D-Pad - Move

## Requierments
* a 3DS system.
* [Scratch Everywhere](https://github.com/ScratchEverywhere/ScratchEverywhere)
